- 我們匯整了 `TVBS`、`信民協會`、`美麗島電子報` 等具代表性的公開民調：
  - **一目了然的長條圖**：清楚標示藍綠主要候選人的支持度百分比與雙方差距（百分點 `pp`）。

- **「如果明天投票，你會把票投給誰？」**

## 💡 常見問題（選民 Q&A）

### Q：我在「民意調查箱」投完票後，別人看到的票數也會增加嗎？
**會的！** 本網站的民意調查箱已串接雲端即時共用資料庫，您投下的一票會立即寫入雲端總票數中，所有開啟網頁的選民都會看到一致的最新票數與得票率。

### Q：為什麼我投完票後按鈕就鎖住了？
為了維護網路民調的公平性與真實性，系統設定為**「每人每天限投一次」**。當您今天完成投票後，系統會記錄您的投票狀態，直到隔天凌晨 `00:00` 後才會重新開放投票。

### Q：網站上的民調與新聞多久更新一次？
網站右上角設有即時時鐘與 **60 秒自動更新計時器**，每分鐘都會自動同步最新的雲端票數與選情新聞；您也可以隨時點擊右上角的「重繪視覺動態」按鈕立即更新。
